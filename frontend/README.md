# Frontend

Клиентская часть проекта отвечает за:
- регистрацию и вход пользователя;
- просмотр списка котов;
- отображение статусов владения;
- создание и редактирование карточек котов;
- визуальную работу со сценарием передержки.

Общий порядок запуска проекта описан в корневом файле `README.md`.
